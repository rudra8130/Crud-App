
# 🧑‍💼 Employee Management System

A fully functional **Employee Management Web Application** that allows users to perform complete **CRUD operations** (Create, Read, Update, Delete) on employee data. The application fetches and manages data using a **JSON API**, providing a smooth and responsive user experience.

---

## 🚀 Features

* 🔐 **Authentication System**

  * Sign In page for secure access

* 🏠 **Home Dashboard**

  * Displays all employee records in a structured format

* ➕ **Add Employee**

  * Add new employee details easily

* ✏️ **Edit Employee**

  * Update existing employee information

* ❌ **Delete Employee**

  * Remove employee records from the system

* 🔄 **API Integration**

  * Employee data is fetched from a JSON API

* 📱 **Responsive Design**

  * Works seamlessly across devices

---

## 🛠️ Tech Stack

* **Frontend:** React.js
* **State Management:** (Redux toolkit)
* **Styling:** CSS / Bootstrap 
* **API:** JSON Server / External JSON API
